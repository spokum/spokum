# Переезд сайта на свой хостинг

Здесь только про сайт. База остаётся в Supabase, её переезд это отдельная история.

## Что уже готово в репозитории

Сборщик `tools/build.mjs` копирует папку `web` в `dist` и сжимает все js и css. Имена файлов и структура папок не меняются, поэтому приложение работает точно так же.

Выкладка `.github/workflows/host.yml` собирает сайт и заливает его на хостинг по SFTP. Пока секреты не заданы, шаг просто пропускается и ничего не ломает.

## Что нужно от вас

### Шаг 1. Закрыть репозиторий

Настройки репозитория, раздел Danger zone, Change visibility, Private. Бесплатно и мгновенно. После этого схему базы, код бота и историю не увидит никто посторонний.

Внимание: публикация на GitHub Pages из закрытого репозитория на бесплатном тарифе не работает. Поэтому закрывать репозиторий нужно вместе с переездом сайта, а не до него.

### Шаг 2. Купить хостинг и домен

Подойдёт любой младший тариф с SSL и SFTP. Смотрите цену при помесячной оплате, а не за три года вперёд.

### Шаг 3. Добавить четыре секрета

Репозиторий, Settings, Secrets and variables, Actions, New repository secret.

| Имя | Что вписать |
|---|---|
| `HOST_SFTP_HOST` | адрес сервера хостинга, например `vh123.timeweb.ru` |
| `HOST_SFTP_USER` | логин от хостинга |
| `HOST_SFTP_PASSWORD` | пароль от хостинга |
| `HOST_SFTP_DIR` | папка сайта, например `/home/u123/spokum.ru/public_html` |

Точные значения хостинг показывает в панели, раздел про FTP или SSH доступ.

### Шаг 4. Запустить выкладку

Actions, слева Publish to hosting, Run workflow. Через минуту сайт открывается по вашему домену.

Дальше каждый пуш в `main` обновляет сайт сам.

## Android

Установленные приложения проверяют обновления по адресу `spokum.github.io`. Поэтому порядок такой и никакой другой:

1. Новый домен работает и проверен.
2. В приложении меняется адрес обновлений на новый домен, собирается новый APK.
3. Новая сборка выкладывается в RuStore, люди её ставят.
4. И только когда почти все обновились, выключается GitHub Pages.

Если выключить Pages раньше, приложения у людей замрут на текущей версии навсегда.

## Про исходники

Код в браузере спрятать нельзя, его скачивает сам браузер. Сжатие делает его нечитаемым с первого взгляда, но восстановимым.

По-настоящему закрывается другое: репозиторий с историей, схемой базы и кодом бота. Это и стоит сделать первым шагом.

Данные защищены не сокрытием кода, а правами в базе. Даже зная весь код, чужую переписку прочитать нельзя, потому что база её не отдаёт.
