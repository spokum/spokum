# СпокУм — как всё запустить

Пошагово. Делай сверху вниз, ничего не пропуская. Занимает минут пятнадцать.

## Что получится

| Часть | Где живёт | Что делает |
|---|---|---|
| Сайт | GitHub Pages | лента, чаты, игры, настройки, профиль, панели админа и модератора |
| База и вход | Supabase | аккаунты, пароли, посты, сообщения, жалобы, наказания |

Сайт статический, база отдельно. Поэтому соцсеть общая: любой человек заходит по ссылке, регистрируется и видит тех же людей и те же посты, что и ты.

---

## Шаг 1. Создать базу в Supabase

1. Открой https://supabase.com и нажми **Start your project**, войди через GitHub.
2. Нажми **New project**.
3. Заполни:
   - **Name** — `spokum`
   - **Database Password** — придумай длинный пароль и **сохрани его себе**, он больше не покажется
   - **Region** — выбери ближайший к твоим пользователям (для России обычно `Frankfurt` или `Stockholm`)
4. Нажми **Create new project** и подожди 1–2 минуты, пока проект поднимется.

## Шаг 2. Создать таблицы

1. В левом меню проекта нажми **SQL Editor**.
2. Нажми **New query**.
3. Открой в этом репозитории файл `supabase/schema.sql`, выдели **весь** текст и скопируй.
4. Вставь в окно SQL Editor и нажми **Run** (или Ctrl+Enter).
5. Внизу должно появиться `Success. No rows returned`. Строки с `NOTICE ... does not exist, skipping` — это нормально, так и должно быть при первом запуске.

Проверить: слева **Table Editor** → в списке появятся `profiles`, `posts`, `messages`, `chats`, `reports`, `punishments`, `mod_strikes`, `audit`, `game_scores`, `announcements`, `call_signals` и другие.

> **После каждого обновления соцсети прогоняйте `supabase/schema.sql` заново.** Файл написан так, что его можно запускать сколько угодно раз: существующие данные не трогаются, добавляются только новые таблицы и колонки. Без этого новые разделы (видео, альбомы, объявления, звонки) будут ругаться на отсутствующие таблицы.

## Шаг 3. Выключить подтверждение почты

Без этого регистрация будет висеть и просить письмо, которого никто не получит.

1. Левое меню → **Authentication**.
2. Вкладка **Sign In / Providers** (в старом интерфейсе — **Providers**).
3. Открой **Email**.
4. Выключи переключатель **Confirm email**.
5. Нажми **Save**.

## Шаг 4. Взять ключи

1. Левое меню → **Project Settings** (шестерёнка внизу) → **API**.
2. Скопируй два значения:
   - **Project URL** — вида `https://abcdefghijklm.supabase.co`
   - **anon public** ключ — длинная строка, начинается с `eyJ...`

**Важно:** ключ `service_role` с той же страницы **никуда не вставляй и никому не показывай**. Он даёт полный доступ к базе в обход всех правил. Нужен только `anon public` — он для этого и создан, его можно держать в открытом коде.

## Шаг 5. Вписать ключи в сайт

Открой файл `web/config.js` и замени пустые строки на свои значения:

```js
window.SPOKUM_SUPABASE_URL = 'https://abcdefghijklm.supabase.co';
window.SPOKUM_SUPABASE_KEY = 'eyJhbGciOi...твой anon ключ...';
window.SPOKUM_API = '';
```

Сохрани, закоммить и запушь:

```bash
git add web/config.js
git commit -m "Подключить Supabase"
git push
```

Можно и без консоли: открой `web/config.js` на github.com, нажми карандаш, поправь, внизу **Commit changes**.

## Шаг 6. Включить GitHub Pages

Это единственный шаг, который нельзя сделать из кода: GitHub не даёт роботам включать Pages, только владельцу репозитория.

1. Зайди в репозиторий на GitHub → вкладка **Settings**.
2. Слева **Pages**.
3. В **Source** выбери **GitHub Actions** (не Deploy from a branch).
4. Перейди во вкладку **Actions** → слева выбери `Deploy web to GitHub Pages` → справа кнопка **Run workflow** → ветка `main` → **Run workflow**.
5. Подожди, пока галочка станет зелёной (около минуты).
6. Вернись в **Settings → Pages** — сверху появится адрес сайта, обычно `https://spokum.github.io/spokum/`.

До включения Pages сборка падает с ошибкой `Get Pages site failed` — это нормально и лечится этим шагом.

Дальше сайт будет обновляться сам при каждом пуше.

## Шаг 7. Забрать себе админку

1. Открой адрес сайта.
2. Нажми **Регистрация**.
3. Юзернейм — **vanya8**, имя любое, пароль от 8 символов.
4. Готово: этот аккаунт сразу получает админку, галочку верификации и молоток разработчика. Так прописано в базе, повторить это другим юзернеймом нельзя.

Регистрируйся первым, пока имя `vanya8` свободно.

## Как этим пользоваться

### Разделы снизу
- **Лента** — текстовые посты с одним фото и тегом настроения, поиск по записям, сохранённое, фильтр по настроению, лайки (двойной тап), комментарии, жалобы, «потяните вниз» для обновления. Видео и альбомы сюда не попадают — для них отдельный раздел.
- **Видео** — ролики и фотоальбомы на весь экран. Листаются вверх-вниз, фото внутри альбома — вбок, с точками-индикаторами. Автоплей у роликов, звук по кнопке, лайк двойным тапом, комментарии, счётчик просмотров. Кнопка **Выложить** спрашивает, что публикуем: видео или несколько фото.
- **Чаты** — поиск людей по юзернейму и словам, личные диалоги, группы, каналы, фото, голосовые, эмодзи, **живые звонки и видеозвонки**, контакты.
- **Игры** — Змейка, Шторм (арена-стрелялка), Лабиринт 3D (от первого лица), Орбита, Дрифт, Пульс, Эхо, Поток. Есть рекорды и таблица лидеров.
- **Настройки** — темы (в том числе Лес и Песок для всех, Аврора, Закат, Королевская и Бездна для премиума), акценты, интерфейс, смена пароля, сессии, проверка обновления приложения.
- **Профиль** — аватар, имя, био, настроение, лайки, записи с вкладками Записи / Альбомы / Видео, вход в панели.

### Звонки

В личном чате две кнопки: камера — видеозвонок, трубка — обычный. Собеседнику приходит входящий экран с зелёной и красной трубкой. Во время разговора можно выключить микрофон, камеру и приглушить звук. Голос и видео идут напрямую между устройствами (WebRTC), сервер только передаёт «рукопожатие».

Если оба собеседника сидят за строгим корпоративным NAT, соединение может не установиться — для таких случаев нужен платный TURN-сервер, его можно добавить позже в `web/js/call.js`.

### Видео и альбомы

Всё это живёт в разделе **Видео**, в ленту не попадает. Кнопка **Выложить** (или **В Видео** в поле для поста) спрашивает, что публикуем:

- **Несколько фото** — выбираете снимки по одному, после каждого приложение спрашивает, добавить ли ещё (до шести, с премиумом до десяти). Смотрятся как ролик на весь экран, листаются вбок.
- **Видео** — телефон предложит снять новое или взять из галереи. Ограничение — 90 секунд и 24 МБ (с премиумом до 3 минут).
- Файлы уходят в хранилище Supabase (бакет `media`), в базе остаётся только ссылка.
- Тап по любой картинке в приложении, включая **статус премиума** рядом с ником, открывает её в полном размере.

### Тихие комнаты

У каждого тяжёлого настроения своя комната. Выбрали настроение в профиле — она открывается сама; выбрали тег у поста — появляется мягкое предложение зайти. В любой комнате уведомления выключены, лента и чаты ждут, сверху идёт таймер.

| Настроение | Комната | Что внутри |
|---|---|---|
| Тревога | Тихая комната | дыхание 4-7-8, опора 5-4-3-2-1, звуки, слова, пузыри |
| Грусть | Тёплый угол | тёплые слова, маленькие шаги, письмо себе, звуки, мягкое дыхание |
| Злость | Комната выдоха | длинный выдох, сжать-отпустить, разряд по шарам, слова, звуки |
| Усталость | Место отдыха | пауза на две минуты, ровное дыхание, звуки, слова, шаги |

Зайти вручную — в профиле кнопка **Тихие комнаты**.

### Дневник настроения

Раз в день, начиная с утра, приложение предлагает записать три-пять предложений о своём состоянии. Записи приватные: их не видит никто, включая админов, — база отдаёт их только автору.

Там же можно выбрать **слово дня** и решить, показывать ли его в профиле рядом с ником. Слово держится сутки с небольшим.

Профиль → **Дневник**: сводка за период (какое настроение чаще, в какие дни недели тяжелее, стало легче или тяжелее, сколько дней подряд), облако слов за месяц — частые слова крупнее — и все записи.

### Админ-панель

Шесть вкладок:

| Вкладка | Что там |
|---|---|
| Аналитика | счётчики сети, активность за неделю, настроение сети, выгрузка списка людей в CSV, копирование сводки |
| Люди | поиск, статусы, премиум, мут, бан, переименование, сброс оформления, удаление всех записей, личное сообщение, копирование ID |
| Контент | все посты, видео и альбомы с быстрым удалением |
| Эфир | объявление на всю сеть: заголовок, текст, тон и срок; висит в шапке ленты, пока человек его не закроет |
| Наказания | все действия модераторов, отмена и предупреждения |
| Журнал | полный аудит действий |

### Статусы (выдаёт админ)
Профиль → **Админ-панель** → **Люди** → нажать на человека:

| Статус | Значок | Что даёт |
|---|---|---|
| Галочка | печать с галочкой | верифицированный пользователь |
| Щит | щит | модератор, открывается панель модератора |
| Молоток | молоток | статус разработчика |
| Админка | звезда | полный доступ к админ-панели |
| Снять все статусы | — | убирает всё сразу |

Там же — **Замутить** и **Заблокировать** с выбором срока и причины.

### Панель модератора
Появляется у того, кому выдали щит. Профиль → **Панель модератора**:
- **Публикации** — посты из ленты, можно снять пост с причиной и наказать автора;
- **Видео** — ролики и альбомы из раздела Видео, с фильтром по типу; можно открыть на весь экран, снять с публикации и наказать автора. Снятые помечаются прямо в разделе;
- **Жалобы** — жалобы людей друг на друга, с приложенными фото, можно наказать, закрыть или отклонить;
- **Мой статус** — сколько предупреждений накопилось.

### Контроль над модераторами
Админ-панель → **Наказания** — видно каждое действие модератора.
- **Отменить** — снимает наказание, снятый пост возвращается в ленту.
- **Отменить и предупредить** — то же самое плюс предупреждение модератору.
- На третьем предупреждении щит снимается автоматически, панель модератора закрывается.

Основателя `vanya8` нельзя забанить, замутить и лишить админки — это защищено на уровне базы.

## Приложение для Android

APK собирается автоматически при каждом изменении и лежит по постоянной ссылке:

**https://github.com/spokum/spokum/releases/download/apk/spokum-latest.apk**

Как поставить на телефон:

1. Открой ссылку в браузере телефона, скачай файл.
2. Нажми на скачанный файл. Android спросит разрешение ставить приложения из этого источника — разреши.
3. Появится иконка СпокУма.

Что внутри: весь интерфейс, шрифты и библиотека связи с базой лежат в самом приложении — оно не тянет ничего со сторонних сайтов, поэтому открывается мгновенно и одинаково выглядит без интернета. Данные берутся из той же базы Supabase, что и сайт, так что аккаунт и переписка общие.

Важно про обновления: сборка подписывается временным ключом, который у каждой сборки свой. Поэтому новую версию поверх старой Android не поставит — сначала удали старое приложение, потом установи новое. Чтобы обновления ставились поверх, нужен постоянный ключ подписи; скажи, если понадобится, это настраивается отдельно.

Пересобрать вручную: вкладка **Actions** → слева **Build APK** → **Run workflow**.

## Если что-то не работает

**«Подтверждение почты включено в Supabase»** — не сделан Шаг 3. Выключи Confirm email и попробуй снова.

**Вверху ленты жёлтая плашка «Автономный режим»** — сайт не видит ключи. Проверь `web/config.js`: обе строки заполнены, коммит запушен, сборка в Actions прошла. Обнови страницу с Ctrl+F5.

**«Юзернейм занят»** — имя уже зарегистрировано, возьми другое.

**«Недостаточно прав»** — действие требует статуса, которого нет у аккаунта. Выдай статус через админ-панель.

**Нет интернета** — приложение и сайт покажут жёлтую полосу сверху и ленту, сохранённую с прошлого раза. Можно листать записи, открывать игры, менять темы. Публикация, чаты и жалобы вернутся вместе со связью.

**Лента пустая** — так и должно быть у новой сети. Никаких ботов и выдуманных людей здесь нет: появятся те, кто зарегистрируется.

**Пропали данные** — если плашка «Автономный режим» висела, всё писалось в браузер, а не в базу. Подключи Supabase и заведи аккаунт заново.

**Хочу почистить базу** — Supabase → SQL Editor → `truncate public.posts, public.messages, public.chats cascade;`

## Локальный запуск (по желанию)

```bash
cd web
python3 -m http.server 8080
```
Открыть http://localhost:8080. Ключи из `config.js` работают и локально.

В репозитории также лежит `server/` — свой бэкенд на Node и SQLite, если когда-нибудь захочешь уйти с Supabase на собственный сервер. Для работы через Supabase он не нужен.

## Что где лежит

```
web/            сайт: index.html, css/app.css, js/
web/config.js   ключи Supabase
supabase/       schema.sql — таблицы, права и серверные функции
server/         запасной бэкенд на Node + SQLite
.github/        автопубликация сайта на Pages
```
