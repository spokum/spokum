# Как повесить СпокУм на spokum.ru

Домен куплен на reg.ru, сервер стоит в Москве. Осталось соединить одно с другим.

Всего три части: адреса в панели reg.ru, сайт на GitHub Pages, база на своём сервере.
Делать строго по порядку, между шагами есть ожидание.

---

## Часть 1. Адреса в reg.ru

Заходите в личный кабинет reg.ru, раздел **Домены**, выбираете `spokum.ru`,
слева пункт **DNS-серверы и управление зоной** (может называться **Управление зоной**).

Там будет список записей. Нужно, чтобы в итоге получилось ровно так:

| Тип | Субдомен | Значение |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `spokum.github.io.` |
| A | `api` | `95.215.56.145` |

Четыре адреса для `@` — это серверы GitHub Pages, они раздают сайт.
Запись `api` — это ваш сервер с базой.

Точка в конце `spokum.github.io.` обязательна, reg.ru её требует.

**Если там уже есть записи, которые ведут на парковку reg.ru** — удалите их.
Обычно это одна A-запись на `@` и одна на `www`.

Сохраняете. Дальше ждёте. Обычно десять минут, иногда час.

---

## Часть 2. Сайт на домене

Пока адреса расходятся, идите в репозиторий на GitHub:

**Settings** → слева **Pages** → блок **Custom domain**.

Вписываете `spokum.ru`, жмёте **Save**.

GitHub проверит адреса. Если ещё не разошлись — напишет ошибку, это нормально,
подождите и нажмите Save ещё раз.

Когда проверка пройдёт, ниже появится галочка **Enforce HTTPS**. Поставьте её.
Она может быть серой минут двадцать, пока GitHub выпускает сертификат.

После этого сайт открывается по `https://spokum.ru`, а старый адрес
`spokum.github.io/spokum` продолжает работать и никуда не денется.

---

## Часть 3. База на домене

Когда `api.spokum.ru` разошёлся, заходите на сервер и запускаете:

```
curl -fsSL -H 'Accept: application/vnd.github.raw' "https://api.github.com/repos/spokum/spokum/contents/server/vds/05-domen.sh?ref=main" -o /root/s5.sh && bash /root/s5.sh
```

Скрипт сам проверит, что домен смотрит на этот сервер, перепишет настройки,
перезапустит что нужно и выпустит сертификат. Минуты три.

В конце он покажет адрес и ключ. Эти две строки присылаете мне,
я меняю их в коде сайта — и всё, СпокУм полностью на своём домене.

**Если что-то пойдёт не так**, скрипт сам напишет команду отката.
Прежние настройки он сохраняет перед изменением.

| Шаг | Сколько ждать |

| Запустили скрипт на сервере | 3 минуты |
| Прислали мне адрес и ключ | минута на правку |

## Как проверить, что адреса разошлись

Не обязательно, но если хочется убедиться до того, как что-то нажимать.
На сервере:

```
getent hosts spokum.ru
getent hosts api.spokum.ru
```

Первая команда должна показать адрес, начинающийся на `185.199.`
Вторая — `95.215.56.145`.

Если показывает старое или ничего — ещё не разошлось, ждите.

---

## Частые заминки

**GitHub пишет «Domain does not resolve»** — адреса ещё не разошлись.
Подождите и нажмите Save снова.

**Enforce HTTPS серая и не нажимается** — GitHub ещё выпускает сертификат.
До часа. Просто ждите, ничего делать не надо.

**Сайт открывается, но выглядит сломанным** — старая версия осталась в памяти
браузера. Закройте вкладку, откройте заново.

**Скрипт пишет «домен смотрит не на этот сервер»** — в записи `api` указан
не тот адрес. Проверьте, что там ровно `95.215.56.145` и ничего лишнего.

---

## Что будет со старыми ссылками

Всё продолжит работать:

- `spokum.github.io/spokum` — останется, GitHub держит оба адреса
- приложение на телефонах — обновится само
- фото и видео, загруженные раньше — открываются как раньше
