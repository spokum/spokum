# Бот оплаты премиума — что куда тыкать

Пошагово. Минут пятнадцать, карта не нужна, платить ни за что не надо.

## Что получится

Человек в приложении жмёт **Настройки → СпокУм Премиум → Оформить премиум**, попадает в бота, выбирает срок кнопкой, платит звёздами Telegram — премиум включается сам, за секунду. Вам делать ничего не нужно, админку для этого открывать не надо.

Бот живёт внутри Supabase, отдельный сервер не нужен. Он не «висит» круглосуточно, а просыпается на каждое сообщение — для человека это неотличимо, а платить не за что.

---

## Шаг 0. Перевыпустить токен бота

**Сделайте это первым делом.** Токен, которым бот подписывает свои запросы, — это пароль от бота. Если он где-то засветился (в переписке, в скриншоте, в чужом чате), любой может писать от имени вашего бота.

1. Откройте `@BotFather`
2. `/mybots` → выберите `@spokum_bot`
3. **API Token** → **Revoke current token**
4. Скопируйте новый токен и никому не показывайте

Дальше в инструкции этот новый токен называется **ТОКЕН БОТА**.

Заодно там же можно причесать бота: `/setdescription`, `/setabouttext`, `/setuserpic`.

---

## Шаг 1. Обновить базу

1. Supabase → **SQL Editor** → **New query**
2. Открыть `supabase/schema.sql` из репозитория, скопировать **весь** текст
3. Вставить → **Run**
4. Внизу `Success. No rows returned`

Появятся таблицы `tg_links`, `link_codes`, `payments` — привязки Telegram, одноразовые коды и журнал платежей.

---

## Шаг 2. Взять сервисный ключ

1. Supabase → **Project Settings** (шестерёнка внизу слева) → **API**
2. Блок **Project API keys** → строка **`service_role`** → нажать **Reveal**, скопировать

Это **не** тот ключ, что лежит в `config.js`. Сервисный ключ даёт полный доступ к базе мимо всех защит. Он живёт только в секретах функции — никогда не кладите его в репозиторий, в `config.js` или в переписку.

Там же, чуть выше, скопируйте **Project URL** (вида `https://xxxxx.supabase.co`) и **Reference ID** (короткая строка из букв, она же в адресе дашборда).

---

## Шаг 3. Придумать пароль вебхука

Просто придумайте любую длинную строку без пробелов, например `spokum-hook-8f3k2j9x`. Она нужна, чтобы никто чужой не мог постучаться в бота и выписать себе премиум. Дальше это **ПАРОЛЬ ВЕБХУКА**.

---

## Шаг 4. Вписать секреты

Supabase → **Edge Functions** → **Secrets** (вкладка вверху) → **Add new secret**. Добавьте четыре штуки:

| Имя | Значение |
|---|---|
| `BOT_TOKEN` | новый токен из шага 0 |
| `SERVICE_KEY` | сервисный ключ из шага 2 |
| `PROJECT_URL` | Project URL из шага 2 |
| `WEBHOOK_SECRET` | пароль из шага 3 |

Имена пишите буква в букву, заглавными.

---

## Шаг 5. Выложить бота

Два пути, выберите любой.

### Путь А — через дашборд, мышкой

1. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**
2. Имя функции: **`telegram`** (именно так, маленькими буквами)
3. Стереть пример, вставить весь текст из `supabase/functions/telegram/index.ts`
4. **Deploy**

### Путь Б — чтобы обновлялся сам при пуше

Один раз добавьте два секрета в GitHub (**Settings → Secrets and variables → Actions → New repository secret**):

| Имя | Где взять |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | supabase.com → аватар справа вверху → **Account Tokens** → Generate new token |
| `SUPABASE_PROJECT_REF` | Reference ID из шага 2 |

Дальше бот выкладывается сам при каждом пуше, как сайт.

После деплоя запомните адрес функции — он вида:

```
https://ВАШ_REF.supabase.co/functions/v1/telegram
```

---

## Шаг 6. Сказать Telegram, куда стучаться

Один раз. Возьмите ссылку ниже, подставьте свои значения и откройте её в браузере:

```
https://api.telegram.org/botТОКЕН_БОТА/setWebhook?url=https://ВАШ_REF.supabase.co/functions/v1/telegram&secret_token=ПАРОЛЬ_ВЕБХУКА
```

Три подстановки:
- `ТОКЕН_БОТА` — сразу после слова `bot`, без пробелов и скобок
- `ВАШ_REF` — Reference ID проекта
- `ПАРОЛЬ_ВЕБХУКА` — строка из шага 3

Должно ответить:

```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

Всё. Бот работает.

---

## Шаг 7. Проверить

1. Напишите `@spokum_bot` команду `/start` — он должен объяснить, что аккаунт не привязан
2. В приложении: **Настройки → СпокУм Премиум → Оформить премиум → Открыть бота**
3. Бот ответит «Аккаунт @вашник привязан» и покажет кнопки с ценами
4. Нажмите любую — придёт счёт в звёздах

Платить для проверки не обязательно: если счёт пришёл — вся цепочка рабочая.

## Деньги

Звёзды копятся на боте. Вывод — через `@PremiumBot` или Fragment в TON: Telegram держит выплату около трёх недель и берёт свою долю, поэтому до вас доходит меньше номинала. Точные проценты и сроки смотрите в справке Telegram, они меняются.

Доход есть доход — в России это закрывается самозанятостью. Это уже не техническая часть.

**Возврат.** Если человек просит вернуть звёзды, у вас есть номер чека из сообщения об оплате. Возврат делается вызовом `refundStarPayment` — ссылкой в браузере:

```
https://api.telegram.org/botТОКЕН_БОТА/refundStarPayment?user_id=ID_ЧЕЛОВЕКА&telegram_payment_charge_id=НОМЕР_ЧЕКА
```

Премиум при этом не снимается автоматически — заберите его из админки вручную.

## Про магазины приложений

Google Play прямо запрещает продавать подписки мимо своего биллинга. У RuStore правила мягче, но кнопка «Оформить премиум» внутри приложения может считаться обходом.

Безопасный вариант, если будут вопросы от модерации: убрать кнопку из приложения и оставить только упоминание бота в описании. Оплата от этого не сломается — привязка делается по коду, а код можно получить и без кнопки. Перед публикацией в RuStore стоит перечитать их правила про цифровые товары.

## Если что-то не работает

**Бот молчит на `/start`.** Проверьте, что вебхук встал:

```
https://api.telegram.org/botТОКЕН_БОТА/getWebhookInfo
```

В ответе должен быть ваш адрес и пустой `last_error_message`. Если там ошибка — она прямо скажет, что не так.

**«Код не подошёл».** Код живёт двадцать минут. Нажмите «Оформить премиум» в приложении заново.

**Оплата прошла, премиум не дали.** Такого быть не должно — бот в этом случае пишет номер чека и просит написать вам. Загляните в Supabase → Table Editor → `payments`: если записи нет, значит привязка слетела. Выдайте премиум руками из админки, деньги у вас остались.

**Бот отвечает через раз.** Смотрите Supabase → Edge Functions → `telegram` → **Logs**, там видно каждый вызов и ошибки.
