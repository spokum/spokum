# СпокУм

Соцсеть про спокойствие и настроение: лента с тегами состояния, мессенджер, игры, настройки и профиль. Плюс админ-панель и панель модератора.

**Запуск за пятнадцать минут — [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).**

## Устройство

- `web/` — сайт, без сборки и зависимостей, публикуется на GitHub Pages
- `supabase/schema.sql` — таблицы, права доступа и серверные функции для Supabase
- `server/` — запасной бэкенд на Node и SQLite, если понадобится свой сервер
- `.github/workflows/pages.yml` — автопубликация сайта при пуше

## Разделы

**Лента** — текст, фото и тег настроения, фильтр по настроению, лайки, комментарии, жалобы.

**Чаты** — поиск людей, личные диалоги, группы и каналы, фото, голосовые, эмодзи, звонок, контакты.

**Игры** — Орбита (стрелялка), Дрифт (платформер), Пульс, Эхо, Поток, таблица лидеров.

**Настройки** — пять тем и пять акцентов, настройки интерфейса, смена пароля, сессии.

**Профиль** — аватар, имя, био, настроение, счётчики лайков и записей.

## Статусы

Галочка — верификация, щит — модератор, молоток — разработчик, звезда — админ. Выдаёт админ из своей панели, там же мут и блокировка.

## Модерация

Модератор снимает посты с указанием причины и разбирает жалобы. Каждое его действие видно админу: любое можно отменить, а за необоснованное — выдать предупреждение. Три предупреждения снимают щит автоматически.

## Безопасность

Пароли и сессии ведёт Supabase Auth. Доступ к данным закрыт политиками row level security: чужие чаты не читаются, флаги статусов не подделываются, наказания проходят только через проверяющие права функции. В коде публикуется только ключ `anon`, рассчитанный на публичность; `service_role` в репозитории нет.
