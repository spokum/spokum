# Как выложить СпокУм в RuStore

Пошагово, сверху вниз. Первый раз занимает около часа, дальше обновления идут сами.

---

## Часть 1. Подпись приложения

Магазин принимает только подписанные сборки. Ключ уже создан, его нужно один раз положить в репозиторий как секрет.

### Шаг 1. Открыть секреты

1. Репозиторий на GitHub → вкладка **Settings**
2. Слева **Secrets and variables** → **Actions**
3. Кнопка **New repository secret**

### Шаг 2. Добавить четыре секрета

Каждый добавляется отдельно: вписать имя, вставить значение, **Add secret**.

| Name | Secret |
|---|---|
| `ANDROID_KEYSTORE` | весь текст из файла `keystore.base64.txt` одной строкой |
| `ANDROID_KEYSTORE_PASSWORD` | пароль от ключа |
| `ANDROID_KEY_ALIAS` | `spokum` |
| `ANDROID_KEY_PASSWORD` | тот же пароль |

### Шаг 3. Собрать релиз

1. Вкладка **Actions** → слева **Build APK** → **Run workflow** → ветка `main` → **Run workflow**
2. Подождать примерно минуту
3. Открыть раздел **Releases** репозитория, тег `apk`

Там появятся два файла:

- `spokum-latest.apk` — для установки вручную и для проверки
- `spokum-latest.aab` — этот файл загружается в RuStore

Если файла `.aab` нет, значит секреты не подхватились: проверьте имена, они чувствительны к регистру.

**Ключ нельзя терять.** Файл `spokum-release.keystore` сохраните в надёжном месте. Без него нельзя выпустить обновление: магазин не примет сборку, подписанную другим ключом.

---

## Часть 2. Публикация в RuStore

### Шаг 1. Аккаунт разработчика

1. Открыть https://console.rustore.ru
2. Войти через Госуслуги или по номеру телефона
3. Выбрать тип: **физическое лицо** или компания. Физлицу нужен только паспорт и ИНН
4. Дождаться проверки данных — обычно до суток

### Шаг 2. Создать приложение

1. В консоли → **Приложения** → **Добавить приложение**
2. Загрузить файл `spokum-latest.aab`
3. Заполнить карточку:
   - **Название**: СпокУм
   - **Категория**: Социальные сети
   - **Возрастной рейтинг**: 12+
   - **Краткое описание**: до 80 символов
   - **Полное описание**: что за приложение и что в нём есть
   - **Иконка**: 512×512, PNG — подойдёт ваш логотип
   - **Скриншоты**: минимум 3 штуки с телефона, вертикальные

Текст для карточки, можно брать как есть:

> **Краткое:** Соцсеть про спокойствие: лента настроений, чаты, тихие комнаты.
>
> **Полное:** СпокУм — социальная сеть, где важнее не охваты, а состояние. Здесь можно рассказать, как прошёл день, и отметить настроение тегом. Есть личные чаты, группы и каналы, голосовые сообщения и стикеры. Для тяжёлых состояний работают тихие комнаты: дыхательные практики, звуки природы, упражнения на заземление и спокойные занятия без очков и рекордов. Личный дневник настроения виден только вам и через неделю показывает, как менялось состояние. Плюс игры на пять минут, темы оформления и приватность по умолчанию.

### Шаг 3. Политика конфиденциальности

RuStore требует ссылку на политику. Она уже лежит в репозитории и открывается по адресу:

`https://spokum.github.io/spokum/privacy.html`

Эту ссылку вставьте в поле **Политика конфиденциальности**.

### Шаг 4. Отправить на модерацию

1. Проверить, что все обязательные поля заполнены
2. Нажать **Отправить на модерацию**
3. Проверка занимает от нескольких часов до трёх дней
4. Ответ придёт на почту; если откажут — в письме будет причина, исправляете и отправляете снова

## Часть 3. Как работают обновления

Это главное, ради чего всё устроено именно так.

### Что обновляется само

Всё содержимое приложения: экраны, лента, чаты, игры, комнаты, дневник, тексты, оформление, исправления ошибок.

Как это работает: при каждом запуске приложение заглядывает на сайт, сравнивает версию и, если появилась новая, фоном скачивает её себе. Внизу появляется плашка **«Доступна новая версия»** с кнопкой **Обновить** — нажатие применяет её мгновенно. Не нажали — применится при следующем открытии.

**Человек скачивает APK один раз и дальше получает все новые изменения сам.** Ничего переустанавливать не нужно.

Чтобы выпустить такое обновление, достаточно изменить файлы в папке `web` и запушить. Через минуту новая версия у всех.

### Что требует новой сборки

Только изменения самой Android-оболочки: разрешения, иконка приложения, название в системе, версия Android. Это редкость — за всё время такое понадобилось пару раз.

В этом случае:
1. Actions → Build APK → Run workflow
2. Скачать новый `spokum-latest.aab`
3. В консоли RuStore → ваше приложение → **Добавить версию** → загрузить файл → отправить на модерацию

Номер версии повышается автоматически, вручную ничего править не нужно.

## Если что-то пошло не так

**В релизе нет файла .aab** — не добавлены или неверно названы секреты подписи. Проверьте все четыре имени.

**RuStore пишет, что подпись неверная** — загружен файл, собранный до добавления секретов. Соберите заново через Run workflow.

**Отказ модерации из-за политики конфиденциальности** — проверьте, что ссылка открывается в браузере.

**Отказ из-за возрастного рейтинга** — в приложении есть пользовательский контент и общение, ставьте 12+ и отметьте наличие пользовательского контента.

**Приложение не обновляется само** — проверьте, открывается ли в браузере `https://spokum.github.io/spokum/version.txt`. Если файла нет, значит не прошла публикация сайта: Actions → Publish site → Run workflow.
